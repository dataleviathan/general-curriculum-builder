# General-Curriculum-Builder

A pipeline to de-duplicate course/journal data, cluster by department into subtopics using TF-IDF + KMeans, and map top journals per subtopic via cosine similarity. Outputs multi-sheet Excel with courses, subtopics, exemplars, and coverage summaries for Sales insights.

The General Curriculum Builder streamlines curriculum analysis by de-duplicating course and journal text, clustering courses into subtopics using TF-IDF and KMeans, and ranking journals via cosine similarity. The tool generates labeled subtopics, exemplar courses, top journal matches, and coverage pivots, all consolidated into a multi-sheet Excel export. It is designed to help teams like Sales and Product Management quickly identify knowledge gaps, align journals to departmental needs, and communicate insights with clarity.
